⚙ API Reference

All endpoints are read-only and require no authentication. Timestamps are RFC 3339 (UTC).

List images

ParameterDefaultDescription
limit50Max records to return
offset0Skip N records (pagination)
complete=1offOnly images with ≥95% lines decoded
min_snr=NoffOnly images with avg SNR ≥ N dB
minutes=NoffLast N minutes (mutually exclusive with since/until)
since=<RFC3339>offImages with rx_end ≥ this time
until=<RFC3339>offImages with rx_end ≤ this time
snr_series=0onOmit the per-second SNR time series (saves bandwidth); avg/min/max are always included
